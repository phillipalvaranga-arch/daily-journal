# My Daily Journal

An installable daily to-do journal. Add tasks, cross off what you finish, write a short journal for the day, and see your daily, weekly and monthly achievements and growth.

Live: https://phillipalvaranga-arch.github.io/daily-journal/

Your tasks, notes and stats are stored on this device. You can optionally sync them across your computer, tablet and phone through a private GitHub Gist. On the Sync screen, paste a GitHub personal access token with only the gist permission. That token stays on the device and is never included in a backup. You can still use Export and Import to save a file yourself.

Reminders: open the Reminders tab (bell) to turn on a morning "Plan my day" and an evening "Check off my tasks" reminder, add your own reminders with a label, time and days, or tap the bell on any task. Tap "Turn on alerts" to allow pop-up alerts on each device. Alerts ring while the app or browser is running (missed ones show when you open the app), with an in-app banner and soft chime. For alerts that always ring, use "Add to my calendar" to download a calendar file with a built-in alert. Reminders sync with the rest of your journal.

Dates and times are shown in Central Time.

The product information and numbers in Achievements and Growth are computed only from the tasks you have entered.
