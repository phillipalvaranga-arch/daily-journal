📅 Alerts that always ring

Pop-up alerts from this app only work while the app or your browser is running (it can be in the background). If the app is closed, a reminder you missed shows up as soon as you open it again.

For alerts that ring even when the app is closed, add your reminders to your phone or computer calendar. Tap Add to my calendar, then open the file that downloads. Your calendar will alert you at that time every day you chose.

On an Android phone, if opening the file does not add it, use the Google Calendar button instead. Google Calendar uses your usual alert setting for new events.

About

My Daily Journal keeps your tasks, notes and stats on this device. You can optionally sync them across your computer, tablet and phone through a private GitHub Gist, using a token you paste on the Sync screen. That token stays on this device and is not included in backups. Dates and times use Central Time. Achievements and growth figures are computed only from the tasks you enter.

Connect this device

You can keep the same journal on your computer, tablet and phone. Sync uses a private GitHub note (called a Gist) on your own GitHub account. This app never asks for your GitHub password. The access token you paste is stored only on this device and is never shown back in full.

  1. Sign in to GitHub in your browser. If you do not have an account yet, create one at github.com first.
  2. Open this page to create an access token with only the “gist” permission: Create a GitHub token.
  3. On that page, confirm that only the gist box is checked, choose an expiration, and click Generate token.
  4. Copy the token now. GitHub will not show it again.
  5. Come back here, paste it below, and tap Connect.

Use a token from the same GitHub account on every device. You can reuse this token or create a new one with the gist permission. Do not share the token with anyone. If it expires, create a new one and connect again.

How it stays in sync

The first device that connects creates a private Gist named “My Daily Journal Sync.” Other devices that connect with a token from the same account find that same Gist automatically. Changes are sent a few seconds after you make them, and again when you open the app or come back to it. If you are offline, the app keeps your changes and sends them when you are back online.

If you edit the same item on two devices before they sync, the later edit is kept. Deleting an item on one device is remembered so it does not come back from the other device, unless that other device changed it more recently.
